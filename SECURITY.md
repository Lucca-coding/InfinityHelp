# Política de segurança

## Relato de vulnerabilidades

Caso encontre um problema de segurança, evite publicar dados pessoais, credenciais ou informações sensíveis em uma issue pública.

Abra um aviso de segurança privado pelo recurso **Security Advisories** do GitHub, quando disponível, descrevendo:

- arquivo e trecho afetado;
- comportamento observado;
- passos para reprodução;
- possível impacto;
- sugestão de correção, se houver.

## Escopo

Esta política se aplica à versão v0.2.8.21 BETA DE TESTE publicada neste repositório.
